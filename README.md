# IAPA Posters

Public image hosting for IAPA educational social media artwork.

Workflow: author a square vector poster in `source/YYYY-MM-DD.svg`; GitHub Actions renders and commits a PNG in `posters/YYYY-MM-DD.png` when image rendering is configured.

Public PNG delivery URL format:
`https://raw.githubusercontent.com/WynMars/iapa-posters/main/posters/YYYY-MM-DD.png`

Only finalized, intended-public educational graphics should be committed. Never commit API keys, tokens, passwords, confidential records, or taxpayer data.
